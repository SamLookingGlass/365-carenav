# 365 CareNav

Phone-style app for 365 Cancer Prevention Society. Open the folder and run:

```bash
python -m http.server 8765
```

Then open http://127.0.0.1:8765/

## Sign in

The feed is open without an account. Registration and bookings ask you to sign up or log in.

- Member: `mei.tan@gmail.com` / `Welcome365`
- Marketing admin: `marketing@365cps.org.sg` / `Market365`

Marketing admin opens the CRM. A member stays on the newsfeed.
